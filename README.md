# Ehtisham Ul Haq - AI & ML Engineer Portfolio

A premium, cinematic, single-page portfolio built with a custom dark editorial design system to showcase expertise in Agentic AI, Machine Learning, Computer Vision, and Full Stack Development.

## 🚀 Live Demo
*(https://ai-ml-portfolio-xi.vercel.app/)*

## ✨ Key Features
- **Cinematic Hero Intro:** Features layered typography, immersive particle animations, and a seamless video-to-image character transition.
- **Skill Matrix HUD:** A futuristic, glassmorphism-styled dashboard displaying proficiencies across Data & Agentic AI, Compute (Python, FastAPI, C++), and Communication.
- **Services (Core Offerings):** Detailed layout highlighting professional capabilities including Agentic AI & Workflows, Custom LLMs & RAG, Computer Vision Systems, and SaaS MVP Development.
- **Recap Projects:** An interactive grid of recent technical work (Autonomous Sales Machine, Brain Tumor Detection, SysSpy, etc.) with integrated demo links.
- **3D Certificate Archive:** An interactive, 3D rotating gallery showcasing certifications.
- **Responsive & Accessible:** Fully responsive across all devices (desktop to mobile) with reduced-motion fallbacks for accessibility.

## 🛠️ Technology Stack
- **Structure:** Semantic HTML5
- **Styling:** Custom Vanilla CSS with a bespoke CSS variables design system, CSS Grid/Flexbox layouts, glassmorphism filters, and complex CSS animations (scanlines, particles, ambient glows).
- **Interactivity:** Vanilla JavaScript (`script.js`) leveraging `IntersectionObserver` for scroll-triggered reveals, active navigation pill tracking, and a custom mouse cursor.
- **Animations:** Custom CSS keyframes and subtle parallax effects.

## 📁 Repository Structure
```text
/site
 ├── index.html       # The main single-page application structure
 ├── styles.css       # Custom design system, HUD components, responsive queries
 ├── script.js        # Scroll observations, GSAP logic, 3D carousel logic
 ├── /certificates    # Official PDF credentials and high-res image previews
 └── /images          # Project screenshots, character assets, and SVG icons
```

## 🔧 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ehtishamazing/AI-ML-Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd AI-ML-Portfolio/site
   ```
3. Run a local server to view the site:
   ```bash
   python -m http.server 8080
   ```
4. Open your browser and navigate to `http://localhost:8080`.
